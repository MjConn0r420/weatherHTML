# Weather, at a glance 🌦️

A sleek, responsive, and lightweight single-file weather application built with vanilla HTML, CSS, and JavaScript. It consumes real-time data from the public [Open-Meteo API](https://open-meteo.com/) to provide instant local forecasts with zero API key configuration required.

## Features

* **Instant Geocoding & Weather Fetching:** Search any city worldwide to retrieve accurate geographic coordinates and live meteorological data.
* **Comprehensive Metrics:** Displays current temperature (with Celsius indicators), dynamic weather descriptions, weather condition icons, relative humidity, and wind speed.
* **Responsive Design:** Features a modern, glassmorphic UI styled with CSS custom properties (`:root`), designed to look stunning across both desktop and mobile viewports.
* **Zero Dependencies:** Built entirely with vanilla web technologies—no heavy frameworks, bundlers, or API keys needed.

## Tech Stack

* **HTML5** (Semantic layout & accessibility attributes)
* **CSS3** (Flexbox, Grid, CSS Variables, and Backdrop Filters)
* **JavaScript (ES6+)** (Asynchronous `async/await` fetch requests & DOM manipulation)
* **API:** [Open-Meteo REST API](https://open-meteo.com/)
